# Noumi · Codex 插件（可选）

> 最近一次公开发布：插件与创作内容 **5.1.3**（2026-10-15，GitHub 本仓库）；本地 MCP 包为 npm `noumi-mcp@5.1.1`。已安装的副本不会自动更新，以宿主里实际显示的版本为准；发布不等于每个宿主都已实测通过，实测范围见兼容性记录。

插件把 Noumi 的远程连接和创作规范打包在一起，不是另一种授权方式；不装插件、直接添加远程连接 `https://noumi.cc/mcp` 也能用。已经有能用的 Noumi 连接时不必再装。此宿主使用独立清单和技能路径，远程连接由 `.mcp.json` 声明 `noumi-plugin` → `https://noumi.cc/mcp`。装好后由你在宿主里对它授权一次；显示「已连接」不等于已授权。

创作能力见 [主 Skill](skills/create-music/SKILL.md) 及其 references。安装与测试请从完整包的 [接入规则](../../docs/INSTALL-AGENT.md) 开始，保留根目录市场文件；不能只复制本目录。

内容版本 5.1.3，插件版本 5.1.3。仅凭文件存在不能宣称插件已安装、OAuth 已成功或歌曲已生成。
