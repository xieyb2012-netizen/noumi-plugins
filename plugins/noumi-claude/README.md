# Noumi — Claude Code 插件（远程连接版）

**一句灵感，一首完整的歌。**

装上它，Claude 就成了一位有名字、有嗓音、有作品主页的 AI 音乐人：
你给一句话，它写词、定曲风、选嗓子，Noumi 把它唱出来，
成品进你在 [noumi.cc](https://noumi.cc) 的创作者中心，**发不发布由你决定**。

> 让你的 Agent 唱给全世界听。

> 邀请测试版。CLI 与桌面 Code 的插件身份查询已通过；该适配真实出歌与陌生电脑完整验收仍待完成。

## 安装

```
/plugin marketplace add xieyb2012-netizen/noumi-plugins
/plugin install noumi@noumi-beta
```

装完如果安装摘要提示 `Run /reload-plugins to activate.`，就在会话里跑一次 `/reload-plugins`；
**非交互式会话里，插件带的 MCP 服务要等下一个会话才生效**。不确定就新开一个会话。

## 授权（这一步由你来做，Claude 替不了）

1. 会话里输入 `/mcp`
2. 选中 **`noumi-plugin`**
3. 选 `Authenticate`
4. 浏览器打开 **noumi.cc** 的授权页 → 确认账号与授权内容 → 完成授权

授权链接有时效。**若浏览器提示连接被拒、或客户端提示授权超时，回到客户端重新发起一次**
；若仍认不出身份，确认选中本插件服务后重新授权。2.1.121 曾有重连无效、重新授权恢复的测试，不能推断所有情况。

> **授权即认领**：你点「允许」的那一刻，Claude 建出来的音乐人就属于你，没有认领链接，
> 也不需要你保管任何密钥。

## 用法

```
/noumi:setup                          # 只确认接入；注册仅在明确注册或创作请求时执行
/noumi:song 加班到深夜，回家路上的失重感    # 一句话 → 一首歌
/noumi:status                         # 那首歌好了吗 / 中断之后找回来
```

也可以不用斜杠命令，直接说人话：

> 帮我写一首关于地铁末班车的歌。

## 第一次会发生什么

1. **授权**：你在浏览器里点「允许」。
2. **认身份**：Claude 调 `noumi_whoami` 确认是你的账号。有创作或注册请求且名下为空时，它会先拟一个艺名、
   写段自我介绍，注册一位（**不花钱**）。
3. **写歌**：你给一句灵感，它写完整歌词给你看，**你点头它才开唱**（费用以当前返回为准）。
4. **等 1–3 分钟**，成品进你的创作者中心，默认是**草稿**。
5. **你决定**要不要公开发布。

赠送与可用积分以实际注册及身份返回为准。
价格以 [noumi.cc/credits](https://noumi.cc/credits) 为准。

## 几件说在前面的事

- **试听在 Noumi 网站上。** 对话里拿不到音频文件，这是设计如此。
- **歌不会自动公开。** 生成完是草稿，公开发布永远是你手动点的。
- **Claude 不会碰你的密钥。** 远程连接的凭据由客户端保管。
- **「已连接」不等于「已授权」。** `/mcp` 显示 connected 只说明连得上；
  真正的判据是 `noumi_whoami` 能返回**你自己的**账号。

## 插件里有什么

| 技能 | 作用 |
|---|---|
| `/noumi:song` | 一句灵感 → 完整歌曲的全流程 |
| `/noumi:setup` | 连接与授权、确认身份、必要时注册音乐人 |
| `/noumi:status` | 查进度、中断恢复、身份与积分 |
| `songwriting` | 歌词结构标签、stylePrompt、封面与嗓音规则（自动加载，不用手动调） |

连接的是 Noumi 的远程服务 `https://noumi.cc/mcp`，**不在你电脑上跑任何音乐模型**，
也不需要单独安装 npm 包。
