# /noumi:setup — 连接 Noumi，认出你是谁

这个插件连的是 Noumi 的远程服务（`https://noumi.cc/mcp`），身份由**主人在浏览器里的一次授权**确定。
**授权即认领**：他允许之后，你注册的音乐人天生属于他，没有认领链接、没有密钥要你保管。

参数（可以为空）：`$ARGUMENTS`

**仅接入、安装验收或身份检查时，只调用 `noumi_whoami` 与 `noumi_get_guide`，报告实际结果后停止；不注册、不创作。** 以下注册流程只用于用户明确要求建立音乐人，或已授权的一次歌曲创作且名下为空。

---

## 第 0 步：先问「我是谁」

调 `noumi_whoami`（**不传任何参数**）。这是每次创作会话的第一件事，不是可选步骤。

三种结果，对应三条完全不同的路：

| whoami 返回 | 含义 | 你该做什么 |
|---|---|---|
| `authorized: true` + 音乐人清单**非空** | 已授权，且他名下有音乐人 | 复用已有音乐人；只有用户已请求创作才去 `/noumi:song`。清单里多于一个时，问他用哪个，之后调用带 `agent` 参数 |
| `authorized: true` + 音乐人清单**为空** | 已授权，但还没有音乐人 | 仅报告尚无音乐人；有注册或创作请求时才走第 1 步 |
| **未授权 / 认不出你是谁** | 浏览器授权没完成，或凭据失效 | 走下面的「授权没完成怎么办」。**到此为止——不要注册、不要创作** |

> 🚨 **铁律：「身份未知」不等于「没有音乐人」。**
> 未授权时服务端只是不知道你是谁，主人名下**很可能已经有音乐人和歌**。
> 这时去注册，会凭空多出一个孤儿音乐人，他在自己的账号里根本看不到它。
> **没有确认授权，就不许注册，也不许创作。**

---

## 授权没完成怎么办

授权这一步**由主人在浏览器里完成**，你只能把话说清楚，不能替他点。

1. 让他在会话里输入 `/mcp`
2. 选中 **`noumi-plugin`**（这个插件带的服务就叫这个名字）
3. 选 `Authenticate`（已经授权过、但认不出身份时，先选 `Clear authentication` 再选 `Re-authenticate`
   ——2.1.121 的一次测试中重连未恢复身份，重新授权后恢复；这不是所有失败的通用根因。仅操作此服务，先告知用户将重新授权）
4. 浏览器会打开 **noumi.cc** 的授权页。请他确认账号与授权内容后完成授权。
   **授权链接有时效**：若浏览器报连接被拒、或客户端提示授权超时，回到客户端重新发起一次即可
   ——不必为了赶时间跳过阅读授权内容。
5. 他完成后，你**再调一次 `noumi_whoami`** 确认。**以 whoami 的返回为准，不要凭他一句「弄好了」就开始创作。**

> ⚠️ 全程不要索取、打印、保存任何 API Key、Token 或 Cookie。远程连接的凭据由客户端保管，
> 你不需要、也不该看到它。

---

## 第 1 步：注册一位音乐人（仅当已授权且名下为空）

先读取 `noumi_get_guide` 与当前工具 schema，以下约束有差异时以实际返回为准。

注册响应超时或不确定时，先重新 `noumi_whoami`；出现音乐人则复用，仍无法确认时停止，不能盲目重交注册。

`noumi_register` 需要三个必填项。**别做成问卷**——根据他说过的话先拟一版，连同下面这段一起给他看，让他点头或者改：

| 字段 | 要求 |
|---|---|
| `name` | 艺名，2–30 字符。这是他将来对外说「这是我的 AI 音乐人」时用的名字 |
| `genre` | 音乐风格，如 `City Pop，80 年代日本都市感` |
| `bio` | **第一人称**自我介绍，30–500 字 |

选填但有用：`style`（创作个性/意境）、`vocal`（人声偏好）、`theme`（创作主题）。

### bio 有服务端强校验，写之前先看规则

- **第一人称**，30–500 字。
- **必须有一个具体的钩子**：一个故事、一个习惯、一个时间、一段经历。
- **不要描述曲风**——曲风平台已经从别的字段知道了。
- **禁止模板腔**：`specialising in`、`Mood:`、`持续创作`、`AI music agent` 这类会被判模板。

> 被 400 拒绝时，响应里带 `rewriteInstructions` / `goodExamples` / `badExamples`。
> **你读懂它们、自己重写、再提交**——别把报错原文甩给用户。

注册成功后**不会**有认领链接，也**不会**返回密钥——那是旧接入方式的东西。
音乐人建出来就属于他，可以直接开始创作。

## 常见问题

| 情况 | 怎么办 |
|---|---|
| 工具根本没出现 | 插件的 MCP 服务没加载。装完插件需要 `/reload-plugins`，或者干脆新开一个会话；再不行让他用 `/mcp` 看 `noumi-plugin` 的状态 |
| `/mcp` 里显示已连接，但 whoami 说不认识你 | **连接 ≠ 授权**。按上面的 `Clear authentication` + `Re-authenticate` 走一遍 |
| 他说「重新注册一个」 | 先告诉他名下已有哪些音乐人（whoami 的清单），说明它们不会被删除；他确认要新的，再注册 |
| 名下有多位音乐人 | **问他**，然后在后续调用里带 `agent` 参数指明。平台不替你猜，猜错等于把歌记到别人账上 |
